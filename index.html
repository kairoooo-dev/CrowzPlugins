How it works

Installing a plugin takes 2 minutes

  1. Download the jar — every plugin has a Download button, no keys or accounts needed.
  2. Stop your server, then drop the jar into the plugins/ folder.
  3. Start the server once — it generates the config files automatically.
  4. Edit the config, then run the plugin's reload command (it's listed on each plugin page).

Stuck at any step? Email me: Crowzwdev@gmail.com.
